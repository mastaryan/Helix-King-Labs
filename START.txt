Helix King Labs — storefront shell

Run:
  cd helix-king-labs
  node server.js

Then open:
  http://localhost:4173

Zero npm dependencies. Node 18+.

What is implemented (playbook objects 1–10):
1. Gate modal — 21+ and permitted-use on one step; optional email; demo Google path
2. Ticker + sticky header with Certificates as a first-class item
3. Proof homepage — documentation headline, proof line, hard number, hero SKU first
4. Catalog — research-name families with dose options; ops SKUs (RT10, TR20…) on every order line; no public price guide
5. Product template — lot links to that lot’s certificate; specs only; volume table
6. Certificate index — search by lot and product; one record per lot
7. Policy pages — terms, shipping, privacy, permitted use
8. Popup + footer email — same documentation gift
9. Copy deck — data/copy-deck.json (allowed / banned / replacements)
10. Cart rules — volume 2/4/10+ and first-order HELIX10; no sitewide sale

Out of scope, by the playbook:
  payments, processors, supply, category legality
